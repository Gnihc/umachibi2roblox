Optional alternative: the same exporter as a Unity Editor tool. Use it only if you work from the
UmaViewer **source project** in Unity 2022.3 (not the release exe). Copy `Assets/Editor/Uma2Roblox`
into the project, press Play in the Version2 scene, then open Tools > Uma2Roblox.
It batch-loads and exports minis without clicking Export Model per character, and it talks to the same Studio plugin.
